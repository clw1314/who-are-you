帮助

这个页面做什么？

它运行的嗅探器，任何网站在你打开的那一刻都能运行。然后把结果写成一段话：你可能来自哪里、现在在哪、用什么、喜欢什么。

把鼠标放在话里的空格上，会显示它来自哪些嗅探器。下面的列表列出每个嗅探器、读取方式（右侧那一列的 API 或请求头）和读到的内容。它们都不会弹出授权提示。

国籍和城市是怎么猜的？

城市来自你的 IP 地址，查的是 Cloudflare 的地理位置库，和广告网络用的是同一类数据库。开了 VPN 的话，就是 VPN 服务器所在的城市。

国籍是根据浏览器语言（zh-TW 指向台湾，pt-BR 指向巴西）和系统时区推测的，这两样开 VPN 都不会变。美式英语是所有设备的默认语言，说明不了什么，这时看时区。

为什么猜不出年龄？

因为浏览器里没有任何地方透露年龄。广告网络是根据你的行为来估计年龄和性别的：去过哪些网站、看了什么、买了什么，常常靠同一个指纹或 Cookie 把各个网站串起来。这个页面这些都不读，所以直接说猜不出，而不是编一个。

浏览器指纹是什么？

你的系统画文字和图形（Canvas、WebGL）、处理声音时的细微差别，装了哪些字体，再加上屏幕和各项设置。把这些合起来算一个哈希，在每个网站上都一样，不需要 Cookie，无痕窗口里也一样。

它和 IP 无关，所以开 VPN 不会改变它。有防护的浏览器（Brave、开了 resistFingerprinting 的 Firefox、无痕模式下的 Safari）会加干扰；「防指纹」那一行会告诉你你的浏览器有没有。

伪装检测怎么用？

用 VPN、代理或者改 User-Agent 时，网站会拿你的各项信息互相对比。系统时区和 IP 对不上、语言是另一个国家的、WebRTC 暴露的地址不是 VPN 的、IP 属于机房、UA 和显卡对不上，这些都会露馅。

想看起来像 VPN 所在国家的人：把系统时区改成一样的，关掉 WebRTC 或者用能让它走 VPN 的浏览器，再换成家宽出口。

这些数据会被保存吗？

不会。除了第一组，其他都是在你的浏览器里读取的，不会离开浏览器。服务器只回答一个请求（/api/me），内容是它从这个请求里本来就能看到的：你的地址、Cloudflare 对这个地址的数据和你的请求头。不记日志，代码开源。

为什么有些行显示「这个浏览器不提供」？

不是每个浏览器都有所有接口。键盘布局、电池、网络类型、内存和 Client Hints 只有 Chromium 内核的浏览器有；Safari 和 Firefox 有意少给信息。读不到，对隐私来说是好事。
